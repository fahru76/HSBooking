# HSBooking

HSBooking is a reusable homestay website platform for independent Malaysian homestay owners. Each owner gets the same maintainable website framework while supplying their own name, branding, property content, amenities, policies, availability, and booking settings.

This is not a multi-property marketplace in the initial scope. The first product slice is a configurable public homestay site, followed by owner-managed content and booking operations.

## Planned stack

- Next.js App Router
- TypeScript
- Supabase
- npm

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```
